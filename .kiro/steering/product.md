# Product — Flash Graveyard

## What this is
Flash Graveyard resurrects dead Adobe Flash web games for the Kiroween
2026 hackathon, category **Resurrection**. Three Flash-era classics —
Snake, Breakout, Memory Match — rebuilt in HTML5 and wrapped in a
Halloween graveyard hub with shared "soul" points.

## Who it is for
Anyone nostalgic for 2000s Flash game portals, and hackathon judges
checking that a dead technology can come back better: playable,
responsive, no installs, no accounts.

## Non-negotiables
- Everything runs client-side from static files. No backend, no build
  step, no paid service, no third-party assets.
- Every game must be genuinely playable and winnable/losable, with a
  difficulty ramp — never a demo that plays itself.
- All art is CSS + emoji. All sound is procedural WebAudio. No
  copyrighted images, music, or code.
- Scores and souls persist in `localStorage` only; the app must work
  fine when storage is blocked.
